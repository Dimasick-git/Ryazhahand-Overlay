## Описание

Ryazhahand Overlay — форк проекта Ultrahand, переработанный и оптимизированный для стабильной работы на Nintendo Switch. Это инструмент управления оверлеями с расширенным функционалом и современным интерфейсом.

## Ключевые отличия от Ultrahand


- Стабильная сборка: исправлены критические баги.  
- Устранены конфликты constexpr строк.  
- Пересобран и подписан ovlmenu.ovl.  
- Добавлены новые темы и улучшен интерфейс.  
- Реализована поддержка русского и других языков.


## Возможности


### Основной функционал

- Меню оверлеев — быстрый доступ ко всем установленным оверлеям.  
- Управление системой — расширенные настройки консоли.  
- Профили игр — сохранение и загрузка конфигураций.  
- Кастомные команды — создание собственных скриптов.  
- Мониторинг — отслеживание температуры, частот и загрузки.  
- Темы оформления — выбор из множества стилей.  
- Мультиязычность — поддержка русского и других языков.


### Продвинутые функции

- Система пакетов — установка модов.  
- Горячие клавиши — быстрый доступ к функциям.  
- Резервное копирование — сохранение настроек.  
- Поиск по оверлеям.  
- Логирование действий.


## Установка


### Требования

- Nintendo Switch с установленным Atmosphère CFW.  
- Tesla Menu (nx‑ovlloader).  
- SD‑карта с достаточным свободным местом.

### Автоматическая установка (рекомендуемый способ)


1. Скачайте последний релиз из раздела [Releases](https://github.com/Dimasick-git/Ryazhahand-Overlay/releases).  
2. Распакуйте архив в корень SD‑карты.  
3. Перезагрузите консоль.  
4. Откройте Tesla Menu (*L + DPad UP + R*).  
5. Выберите Ryazhahand Overlay.

### Ручная установка: структура файлов на SD‑карте


При ручной установке разместите файлы согласно следующей структуре (пути указаны относительно корня SD‑карты — `sdmc:/`):


```
sdmc:/
├── switch/
│   ├── .overlays/
│   │   └── ovlmenu.ovl          # Основной файл оверлея
│   └── packages/                # Директория для пакетов модов
└── config/
    └── ryazhahand/
        ├── config.ini           # Файл конфигурации приложения
        └── lang/              # Директория с языковыми файлами
```

**Пояснения к структуре:**

- `switch/.overlays/ovlmenu.ovl` — основной исполняемый файл оверлея.
- `switch/packages/` — папка для хранения устанавливаемых пакетов модов (расположена в директории `switch`, как и `.overlays/`).
- `config/ryazhahand/config.ini` — конфигурационный файл приложения.
- `config/ryazhahand/lang/` — папка для языковых файлов интерфейса.


**Важные замечания:**

1. Все пути должны быть указаны точно, как в примере (с учётом регистра).
2. Если какие‑либо директории отсутствуют, создайте их вручную.
3. Директория `packages/` теперь корректно размещена в `switch/`, согласно вашему уточнению.

### Обновление с Ultrahand

1. Удалите старые файлы Ultrahand.  
2. Установите Ryazhahand Overlay.  
3. Настройки будут автоматически конвертированы.

## Использование


### Основные горячие клавиши


- *L + DPad UP + R* — открыть Tesla Menu.  
- *A* — выбрать/подтвердить.  
- *B* — назад/отмена.  
- *X* — дополнительные опции.  
- *Y* — поиск.  
- *Plus* — настройки.

### Первый запуск


1. Выберите Ryazhahand Overlay.  
2. Ознакомьтесь с приветственным меню.  
3. Настройте язык и тему.  
4. Начните использование.

### Создание пакетов для Ryazhahand Overlay


Пакеты позволяют автоматизировать установку модов, конфигурационных файлов и выполнение команд на Nintendo Switch. Формат — обычный текстовый файл с секциями в INI‑подобном синтаксисе.

#### Структура файла пакета

Файл пакета состоит из трёх обязательных секций:


1. **`[Package Info]`** — основные метаданные пакета.  
2. **`[Files]`** — список копируемых файлов.  
3. **`[Commands]`** — команды, выполняемые после копирования файлов.

#### Детальное описание секций

**1. `[Package Info]` — метаданные**

Обязательные поля:
- `name` — название пакета (отображается в интерфейсе).
- `author` — имя автора/разработчика.
- `version` — версия пакета (формат `x.y.z`).
- `description` — краткое описание функционала.

Пример:
```ini
[Package Info]
name=Улучшенные текстуры
author=Иван Иванов
version=1.0.0
description=Замена стандартных текстур на HD-версии
```

**2. `[Files]` — копирование файлов**

Формат записи:  
`file<номер>=<источник> -> <назначение>`


- `<источник>` — путь к файлу на SD‑карте (`sdmc:/...`).
- `<назначение>` — целевой путь в системной памяти.

Особенности:
- Пути указываются полностью, начиная с `sdmc:/` или `/`.
- Поддерживаются подстановки (если реализованы в Ryazhahand).
- Каждый файл — отдельная строка с уникальным номером.


Пример:
```ini
[Files]
file1=sdmc:/packages/textures/high/wall.png -> /atmosphere/exefs_patches/wall.png
file2=sdmc:/packages/textures/high/floor.png -> /atmosphere/exefs_patches/floor.png
```

**3. `[Commands]` — выполнение команд**

Формат записи:  
`cmd<номер>=<команда>`

Поддерживаемые команды (стандартные для Switch):
- `mkdir <путь>` — создать директорию.
- `reboot` — перезагрузить консоль.
- `rm <файл>` — удалить файл.
- `cp <источник> <назначение>` — скопировать файл (альтернатива секции `[Files]`).
- `chmod <права> <файл>` — изменить права доступа.

Пример:
```ini
[Commands]
cmd1=mkdir /atmosphere/exefs_patches
cmd2=reboot
```

#### Полный пример пакета

```ini
[Package Info]
name=HD‑текстуры для игры X
author=Алексей Петров
version=1.2.0
description=Пакет заменяет стандартные текстуры на версии в разрешении 4K

[Files]
file1=sdmc:/my_mods/hd_textures/wall.png -> /atmosphere/exefs_patches/wall.png
file2=sdmc:/my_mods/hd_textures/floor.png -> /atmosphere/exefs_patches/floor.png

[Commands]
cmd1=mkdir /atmosphere/exefs_patches
cmd2=reboot
```

#### Рекомендации по созданию пакетов

1. **Тестирование**: всегда проверяйте пакет на резервной копии данных.
2. **Версионирование**: обновляйте `version` при изменениях.
3. **Пути**: используйте полные пути с указанием `sdmc:/` для файлов на SD‑карте.
4. **Резервные копии**: добавляйте команды `cp` для сохранения оригинальных файлов.
5. **Документация**: в `description` указывайте совместимость и требования.


#### Размещение пакета

Сохраните файл с расширением `.ini` (например, `hd_textures.ini`) в директорию:  
`sdmc:/switch/packages/`


После этого пакет будет доступен для установки через интерфейс Ryazhahand Overlay.
