# UI Ryzhand Overlay

Краткое описание навигации и основных экранов.

## Открытие оверлея

`+` (зажать) → выбрать **Ryzhand** в списке оверлеев Tesla-меню.

## Главный экран

После запуска показывается список доступных категорий:

- **Пакеты** — установленные `.ini`-пакеты команд (создание/копирование/моды).
- **Оверлеи** — другие `.ovl` в `/switch/.overlays/`. Через `A` — запуск, `X` — отметить избранным.
- **Настройки** — конфигурация Ryzhand.
- **Прочее** — LED-подсветка (v2.3.0+), проверка обновлений, «О программе».

Навигация: D-pad / стик, `A` — выбор, `B` — назад, `+` — выход в Horizon.

## Настройки

- **Внешний вид** — выравнивание текста, переход-эффекты, баннер.
- **Сканер обновлений** *(по умолчанию выкл)* — включает фоновую проверку GitHub-релизов смежных оверлеев. Расход трафика: \~50 КБ при каждом запуске.
- **Язык** — Русский / English.
- **Логирование** — для отладки.

## Управление подсветкой

UI «Свечение LED» в главном меню. Настройки кешируются в `/config/ryazhahand/led.ini` (записывается при выходе из UI):

```ini
mode=onpress       ; off | solid | pulse | fade | onpress
target=auto        ; auto | home | joyconL | joyconR | lite_all
brightness=80      ; 0..100
pulse_interval=500 ; миллисекунд между импульсами
color_r=255
color_g=128
color_b=64
```

Физическим применением занимается sysmodule `ryazha-led` (title `0100000000000ED1`), который ставится из `extra/sysmodules/` вместе с оверлеем. Автодетект железа — Switch Lite получает HOME LED через `liteswitch-led` ветку, Joy-Con / OLED — через `sys-notif-LED` ветку.

## Пакеты

Каждый пакет — папка `/switch/.packages/<имя>/` с `package.ini`. Подробнее — [`PACKAGES_RU.md`](PACKAGES_RU.md).

## Проверка обновлений

*По умолчанию выключена* (см. CHANGELOG). После включения сканер сравнивает версии всех `.ovl` в `/switch/.overlays/` с релизами на GitHub. Результаты — на экране **Пакеты → Обновления**.
